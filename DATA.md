# MOT17 data and experimental split

Download MOT17 from the [official dataset page](https://motchallenge.net/data/MOT17/). Its source paper is Dendorfer et al., *MOTChallenge: A Benchmark for Single-Camera Multiple Target Tracking*, IJCV 2021 ([paper](https://link.springer.com/article/10.1007/s11263-020-01393-0)). Check the current terms on the download page before using or redistributing footage. This repository excludes videos, frames, annotations, and detection files from Git. TrackEval is a separate project under its [MIT license](https://github.com/JonathonLuiten/TrackEval/blob/master/LICENSE); its code is not copied here. Pretrained appearance-model terms will be recorded when that model is selected.

Expected local layout:

```text
data/MOT17/train/MOT17-02-FRCNN/
  seqinfo.ini
  img1/000001.jpg ...
  det/det.txt
  gt/gt.txt
```

The initial detector choice is the **official FRCNN public detections**, consistently used for every tracker variant. The MOT17 training scenes are 02, 04, 05, 09, 10, 11, and 13. The project split is generated by shuffling those sorted base scene IDs with Python `random.Random(1704)` and holding out the final two. Exact committed split:

| Partition | Base scenes | Sequence names with fixed detector |
|---|---|---|
| Development | 02, 04, 05, 09, 13 | `MOT17-{02,04,05,09,13}-FRCNN` |
| Held-out | 10, 11 | `MOT17-{10,11}-FRCNN` |

The three detector versions of a base scene share its group. If DPM or SDP is investigated later, its version of a scene must stay in the same partition. Identity values are local to each sequence. Appearance training may use development identity annotations only. Held-out identity annotations are reserved for evaluation. Hidden test annotations are never used.

The downloaded FRCNN files use seven columns for detections (`frame,id,left,top,width,height,score`) and nine for training annotations (those seven plus class and visibility). The [official TrackEval result format](https://github.com/JonathonLuiten/TrackEval/blob/master/docs/MOTChallenge-Official/Readme.md) uses ten columns. Frame and top-left box coordinates are 1-based in the files. The parser converts boxes to zero-based internal coordinates and back for results. It validates finite values, frame indices, confidence in `[0,1]`, and detection intersection with the image. Some official rows are not ordered by frame, so the adapter returns frames in numeric order while preserving within-frame file order. Some ground-truth boxes extend beyond image edges or entirely off screen at low visibility; they remain unmodified for annotation reading. The `--min-confidence` threshold filters detections deterministically. The same threshold and detection files must be used in every ablation. Results contain ten columns with unused world coordinates set to `-1`.

To fetch only the seven FRCNN training sequences directly from the official ZIP without downloading DPM, SDP, or hidden-test files, run `python3.12 scripts/fetch_mot17.py`. It uses HTTP byte ranges and places files under `data/MOT17/train/`. The ZIP is about 5.86 GB; the selected FRCNN members total about 873 MB compressed. The downloader leaves completed files in place if interrupted and rerun.

Run `pedtrack audit-data --data-root data/MOT17 --partition development` and repeat for `held_out` to check every expected frame path, the first and last frame's actual dimensions, and parsed detection/annotation counts. The audit does not modify data.
